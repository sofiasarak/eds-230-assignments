# create wrapper function
c_wrapper <- function(K, r, g, Cinitial, simtimes, odefunc, metricfunc) {
  
  # create parameter list
  params <- list(K = K, r = r, g = g)
  
  # run ode
  result <- ode(y = Cinitial, times = simtimes, func = odefunc, parms = params, method="euler")
  
  # results as a data frame
  result = data.frame(time=result[,1], dC=result[,2])
  
  # compute metrics
  metrics <- metricfunc(as.data.frame(result))
  return(metrics)
}

# create function to compute metric, which is maximum forest size
compute_growth_metric <- function(result) {
  # first add maximum population
  maxforestsize <- max(result$dC)
  
  # return results
  return(list(maxforestsize = maxforestsize))
}

From the first-order Sobol indices, we can see that with no consideration of co-variance between parameters, K, or carrying capacity, has the largest effect on maximum forest size. From the total sensitivity index (or T), we see a similar pattern, with carrying capacity contributing the most – by far – to maximum forest size over 300 years.

These results suggest that climate change’s influence on carrying capacity will significantly impact maximum forest size. Variables that impact carrying capacity include climate, water availability, nutrients, and space/habitat, all of which climate change affects in the natural environment.
